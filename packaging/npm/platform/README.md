# codegraph platform binary

This package holds the prebuilt `codegraph` binary for one OS/CPU pair. Do not install it
directly: install `@crowbett/codegraph`, which depends on the right platform
package through `optionalDependencies` and puts `codegraph` on your PATH.

See https://github.com/crowbett/codegraph/blob/main/docs/INSTALL.md.
